# 最近五次更新的问题修复（2026-10-17）

本轮基于 `8011169`，修复最近五次更新审查中发现的编译、QAgent 通信、任务统计、MFA 与迁移相关问题。

## 修复内容

- 任务查询：修复进度计算中未定义的时间变量，统计 SQL 补全分组；缺失或非法结束时间不再产生负耗时。
- QAgent：解密后的 JSON 请求体重新交给 ASGI/FastAPI 消费，修复请求挂起；实体绑定兼容 Pydantic 1/2；恢复受 snippets 路径白名单约束的 `/writeFile` 路由。
- TOTP：新密钥使用标准 Base32，同时兼容历史 Base64URL 密钥；禁止直接覆盖已确认的绑定；绑定确认与时间片消费采用原子更新，资料或策略更新不会回写旧密钥和旧消费状态。
- Passkey：修复 RSA COSE 模数与指数读取，并支持不同 CBOR 字段顺序；支持无用户名发现式登录，同时保持挑战与账号归属校验。
- 管理员认证：关闭或切换已启用的 MFA、解绑 TOTP、删除 Passkey 需要当前密码；MFA 策略必须显式提供。会话标记单调轮换、严格匹配，改密与管理员代改密码均吊销旧会话。
- 响应与认证边界：管理员敏感字段不进入 Jackson/Fastjson 响应或实体日志；非法会话密文与误用的 MFA 临时票据按未认证处理；正式 JWT 缺失 scope 的情况正常识别，页面认证成功后正确放行。
- 信息上报：默认关闭，不再内置上报密钥；启用方式与外联内容见 [reporting.md](reporting.md)。
- 迁移：修复加密请求与响应、归档残片续传及完整性判断、UTF-8 日志字节偏移与多来源独立游标；增加迁移任务内的目标 VMID 冲突防护，修正未提交目标时的失败续跑阶段。

## 升级兼容

- 升级后管理员应重新登录，旧会话可能已失效。
- 调用 MFA 高危操作的客户端需要提交当前 `password`；修改策略必须显式传入 `mfaType`。接口说明见 [mfa-passkey.md](mfa-passkey.md)。
- 迁移日志 `offset` 与 `nextOffset` 改为不透明字符串，客户端应原样回传，不能转换为数字。旧数值游标按首次请求处理。
- 本轮没有数据库结构变更；SQL 文件仅更新 TOTP 密钥格式注释。
